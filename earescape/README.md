# 막귀탈출 (EarEscape) — TOP 10 브랜드 이어폰·헤드폰 RAG 추천 & 비교 웹페이지

개발을 모르는 사용자도 로컬 PC에서 Rust 명령어 한 번으로 실행해 과제 시연·사용할 수 있는 **미니멀 밝은 매거진 스타일**의 오디오 추천·비교 웹 애플리케이션입니다.

## 주요 기능
- **TOP 10 브랜드 큐레이션 정책**:
  - 일반 8개사(Apple, Samsung, Sony, Bose, Sennheiser, Anker, QCY, Shokz): **최근 1년 이내 출시 신제품**만 자동 포함
  - 예외 2개사(Shure, Westone Audio): 출시일과 무관하게 **대표 인기 스테디셀러** 상시 포함
- **정밀 취향 진단 (`/`)**: 저음·중음·고음 슬라이더(1~5) + 원클릭 프리셋, ANC 유무, 착용 방식(커널/오픈/골전도/오버이어/유선 IEM), 예산 입력 → 맞춤 TOP 3 추천
- **온디맨드 `[데이터 수집]` 버튼**: 상단 헤더 버튼을 누를 때마다 10개 브랜드 공식 소스를 점검하고, 정책 필터링 후 SQLite DB 및 RAG 벡터 인덱스를 실시간 진행률(SSE)과 함께 갱신
- **AI 사운드 컨시어지 (`/chat`)**: SQLite FTS5 + 순수 Rust 코사인 유사도(RRF) 하이브리드 RAG 추천 (Gemini API 키 미입력 시에도 오프라인 한국어 폴백 엔진으로 중단 없이 시연 가능)
- **스마트 비교 스튜디오 (`/compare`)**: 최대 4개 제품 6축 사운드 레이더 차트, `[차이점만 보기]` 비교표, AI 3줄 비교 결론
- **입문자 음향 사전**: 우측 슬라이드 드로어에서 12개 핵심 음향 용어를 쉬운 비유로 확인

## 비개발자용 3단계 실행 가이드

### 1단계. Rust 설치 (최초 1회)
- **Windows / macOS**: [https://rustup.rs](https://rustup.rs)에서 설치 프로그램을 내려받아 기본 옵션으로 설치합니다.
- 터미널(PowerShell 또는 Terminal)에서 `cargo --version`을 입력해 버전이 나오면 준비 완료입니다.

### 2단계. 환경 설정 (선택)
- 프로젝트 폴더(`earescape/`)에서 `.env.example`을 복사해 `.env` 파일을 만듭니다.
- Gemini API 키가 있으면 `GEMINI_API_KEY=...`에 입력하세요. **키를 비워두어도 로컬 한국어 RAG 폴백 모드로 모든 기능이 정상 동작합니다.**

### 3단계. 테스트 및 서버 실행
```bash
# 1) 정책·진단·RAG·수집기 자동 테스트 실행
cargo test

# 2) 웹 서버 실행 (최초 1회 컴파일에 1~2분 소요)
cargo run
```
실행 후 브라우저에서 **`http://localhost:3000`** 으로 접속하면 바로 사용할 수 있습니다.
